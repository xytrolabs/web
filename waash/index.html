Features

Why WAASH?

👀 FISH Autosuggestions

Ghost-text predictions as you type — accept with the arrow key. Predicts from history, paths, and common idioms.

🎱 Syntax Highlighting

Commands, options, strings, variables, and operators colorized live as you type.

🧮 BASH Heredocs

Full support: <<EOF, <<-EOF, <<'EOF', and herestrings <<<.

📈 Indent Scripting

Write scripts in Indent — readable, simple, powerful. Bare commands work directly in scripts.

⏱ Command Timing

See how long each command took, right in the prompt — just like FISH.

🏠 Cross-Distro

Static Rust binary. One installer works on Debian, Fedora, Arch, openSUSE, and more.
