Quickstart

Every first API key comes with $1.00 free credit. Create a key, then send your first request in about a minute.

1. Create an API key

Sign in at valisapis.xytro.site and create a key. Keys look like valis_…. Your balance is shared across all of your keys.

2. Send a request (cURL)

curl https://ai.xytro.site/v1/chat/completions \
  -H "Authorization: Bearer valis_xxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "xael-turbo",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'

3. Switch from OpenAI in one line

Use your existing OpenAI client and point it at Valis:

# Python (openai package)
client = OpenAI(api_key="valis_xxxxxxxx", base_url="https://ai.xytro.site/v1")

Authentication

Authenticate with your API key in the Authorization: Bearer header:

Authorization: Bearer valis_xxxxxxxx

Missing or invalid keys return 401. A 0 balance returns 402 (insufficient balance).

Keys can be bound with a default system prompt and a default knowledge base so every request made with that key automatically uses them — configure via the dashboard or PATCH /v1/keys/:key.

Chat completions

POST/v1/chat/completions — generate a chat completion. Rate limit: 60 req/min per key.

Request body

FieldTypeDescription
modelstringOne of the model IDs above (default xael-nano).
messagesarrayRequired. Chat messages (system/user/assistant).
streamboolStream tokens as SSE (see below).
temperaturenumberSampling temperature. Defaults per model.
promptstring/objectCustom system prompt — a saved preset name, inline text, or {"content":"…"}. Overrides any system message.
response_formatobjectForce JSON: {"type":"json_object"}.
tools / tool_choicearray / stringFunction/tool calling (OpenAI-compatible).
ragobjectAttach a knowledge base: {"kb":"kb_…"}. Sources returned as rag.sources.

Response

Response shape is OpenAI-compatible. Valis adds helpful fields:

  • cached: true — served from cache (billed at 7.5%).
  • semantic: true + similarity — a near-duplicate answer reused via semantic cache.
  • reasoning_content — the model's reasoning/thinking text (Think models).
  • rag.sources — cited knowledge-base excerpts.
  • fallback — served by a fallback model.

Streaming

Set "stream": true to receive tokens as an SSE stream of data: chunks, ending with data: [DONE]. Each chunk is an OpenAI-format completion chunk with choices[0].delta.content (and delta.reasoning_content for Think models).

curl https://ai.xytro.site/v1/chat/completions \
  -H "Authorization: Bearer valis_xxxxxxxx" \
  -d '{"model":"xael-turbo","stream":true,"messages":[{"role":"user","content":"hi"}]}'

JSON mode

Force structured output with response_format:

# Python
resp = client.chat.completions.create(
  model="xael-turbo",
  response_format={"type": "json_object"},
  messages=[{"role":"user","content":"Return JSON: {\"name\": , \"age\": }"}],
)

Tool calling

Pass tools (OpenAI function schemas) and optionally tool_choice. The model emits tool_calls in the assistant message. Turbo is the reliable tool-calling model; Think/Think XL tool requests are auto-routed to Turbo.

Caching

Answers are cached by default. Repeating the same or a semantically similar request is served instantly from cache and billed at 7.5% of the normal price.

  • Clearing the cache wipes your cached history. Only your cache is affected.
  • Use POST/v1/cache/clear to clear it (dashboard: Clear Cache).

RAG knowledge bases

Upload documents, then chat over them with citations. RAG pipelines you over your own data — hosted on Xytro hardware.

1. Create a KB

curl -X POST https://ai.xytro.site/v1/rag/kbs \
  -H "Authorization: Bearer valis_xxxxxxxx" -H "Content-Type: application/json" \
  -d '{"name":"Product docs"}'

2. Add documents

curl -X POST https://ai.xytro.site/v1/rag/kbs/kb_xxx/documents \
  -H "Authorization: Bearer valis_xxxxxxxx" -H "Content-Type: application/json" \
  -d '{"text":"Valis AI is built by Xytro Labs and runs on our own hardware."}'

Plain text is auto-chunked and embedded. You can pass documents (array of {text, id}) to tag sources.

3. Query (with citations)

curl -X POST https://ai.xytro.site/v1/rag/query \
  -H "Authorization: Bearer valis_xxxxxxxx" -H "Content-Type: application/json" \
  -d '{"kb":"kb_xxx","query":"Who builds Valis AI?"}'

Returns an answer plus sources with excerpts and relevance scores. You can also attach the KB directly to a chat via rag: {"kb": …}.

Embeddings

POST/v1/embeddings — generate xael-embed vectors (768-dim). Accepts a string or array of strings.

resp = client.embeddings.create(model="xael-embed", input="Valis rocks")
vector = resp.data[0].embedding
