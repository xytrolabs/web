# Xytro Labs Web

Source for the public Xytro Labs websites — the landing/marketing pages and the
documentation sites for each product.

## Repo layout

| Path | Site | Public URL |
|------|------|-----------|
| `index.html`, `404.html` | Homepage / landing | `xytro.site` |
| `account/` | Account portal | `xytro.site/account` |
| `login/` | Login redirect | `xytro.site/login` |
| `privacy/` | Privacy Policy | `xytro.site/privacy` |
| `terms/` | Terms of Service | `xytro.site/terms` |
| `waash/` | WAASH shell | `xytro.site/waash` |
| `indent/` | Indent language | `indent.xytro.site` |
| `zor/` | Zor transpiler | `zor.xytro.site` |
| `nova/` | NOVA collaboration + Python SDK | `nova.xytro.site` |
| `balance/` | Balance / credits top-up | `balance.xytro.site` |

## Overview

Xytro Labs builds privacy-first software: AI-powered email, cloud storage,
identity, an AI assistant (Valis AI), language tooling (Indent, Zor), a shell
(WAASH), and collaboration (NOVA).

The repository contains the **static** websites and documentation for these
products. Product backends and the applications themselves are not published
here.
